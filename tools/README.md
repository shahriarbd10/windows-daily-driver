# Tools Folder

Create one subfolder per utility tool.

Recommended structure for each tool:

- `<tool-name>/README.md` - Purpose, setup, usage, examples
- `<tool-name>/src/` - Source code
- `<tool-name>/tests/` - Tool-specific tests
- `<tool-name>/assets/` - Icons, sample input/output, static assets

Naming guideline:

- Use kebab-case folder names, for example: `file-rename-assistant`
